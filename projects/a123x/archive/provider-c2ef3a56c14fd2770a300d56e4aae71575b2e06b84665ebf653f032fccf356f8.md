用途：

Creates a threshold task for S16 data to 8-bit data.

文档声明（与当前头文件分别留证）：

MBP_S32 MBI_CVE_Thresh_S16(CVE_HANDLE *pCveHandle, CVE_SRC_IMAGE_T *pstSrc, CVE_DST_IMAGE_T
*pstDst,CVE_THRESH_S16_CTRL_T *pstThrS16Ctrl, MBP_BOOL_E bInstant)

参数说明：

Parameter name Description input/output
pCveHandle Pointer to the handle, can not be null output
pstSrc Pointer to the source data, can not be null input
pstDst Pointer to the output data, can not be null. output
pstThrS16Ctrl Thresh S16 control parameter pointer,can not be null input
bInstant Return the result flag in time input

返回值：

Return value Description
0 success
non-zero failure

调用约束：

The algorithm has the following four modes of operation:
CVE_THRESH_S16_MODE_S16_TO_S8_MIN_MID_MAX:
-32768<=lowThr<=highThr<=32767; -128<=minVal、midVal、maxVal<=127.
CVE_THRESH_S16_MODE_S16_TO_S8_MIN_ORI_MAX
-129<=lowThr<=highThr<=127; -128<=minVal、maxVal<=127.
CVE_THRESH_S16_MODE_S16_TO_U8_MIN_MID_MAX:
-32768<=lowThr<=highThr<=32767; 0<=minVal、midVal、maxVal<=255
CVE_THRESH_S16_MODE_S16_TO_U8_MIN_ORI_MAX:
-1<=lowThr<=highThr<=255; 0<=minVal、maxVal<=255.
Isrc1(xi,yi) corresponds to pstSrc, Iout(x0,y0) corresponds to pstDst, and mode, lowThr, highThr, minVal, midValand
maxVal correspond to enMode, s16LowThr, s16HighThr, un8MinVal, un8MidVal, and un8MaxVal. For details,
see Figure 2.12.
Figure 2.12 Four Thresh_S16 threshold modes
