用途：

Gaussian mixture model defines K states to represent the color of each pixel. The value of K is generally
between 1 and 5. Each state of K States is represented by a Gaussian function. Some of these states represent the
pixel value of the background, and the rest represent the pixel value of the moving foreground.

调用约束：

The pixel-level parameter control is added to GMM by referring to MOG and MOG2 of the OpenCV.
The source image type of pstSrc must be U8C1 or U8C3_PACKAGE during GMM background modeling for gray-scale
images or RGB images respectively.
The model update parameter pstFactor indicates the U16C1 image type. Each element is represented by 16 bits. The
lower eight bits are the sensitivity coefficient for controlling the variance multiple during model matching, and the
upper eight bits are the foreground model duration update coefficient.
DS=0 is not supported when the input source image resolution is 1280x720.
