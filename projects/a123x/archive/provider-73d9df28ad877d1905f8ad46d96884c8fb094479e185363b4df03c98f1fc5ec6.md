AML_DMA_MODE_SET_3BYTE
3-byte filling mode: Only srcPtr is used. Source data is filled with the lower three bytes of u64Val. If the number
of last bytes in a row is less than3 bytes, data is filled with the lower bytes of u64Val.
AML_DMA_MODE_SET_8BYTE
8-byte filling mode: Only srcPtr is used. Source data is filled with the bytes of u64Val. If the number of last
bytes in a row is less than 8 bytes, data is filled with the lower bytes of u64Val.
