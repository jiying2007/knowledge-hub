用途：

Creates a max pooling or average pooling task.

文档声明（与当前头文件分别留证）：

MBP_S32 MBI_CVE_POOLING(CVE_HANDLE *pCveHandle, CVE_IMAGE_T *pstSrcImage, CVE_IMAGE_T *pstDstImage,
CVE_POOLING_CTRL_T *pstPoolingCtrl, MBP_BOOL_E bInstant);

参数说明：

Parameter name Description input/output
pCveHandle
Pointer to the CVE task handle. input/output
pstSrcImage Source image. input
pstDstImage Destination image. output
pstPoolingCtrl Pooling control parameters. input
bInstant Specifies whether the task result is waited for before the call returns. input

返回值：

Return value Description
0 Success.
non-zero Failure.

调用约束：

The control structure is CVE_POOLING_CTRL_T . enMode selects AVG or MAX pooling; u8NChannel , u8Stride ,
u8KSize , zero point, and top/left padding configure the operation. The header does not define the exact tensor
layout.
