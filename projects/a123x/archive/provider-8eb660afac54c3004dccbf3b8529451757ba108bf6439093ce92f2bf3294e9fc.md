Creates a multi-layer pyramid LK optical flow calculation task.

文档声明（与当前头文件分别留证）：

*pstNextPts, CVE_DST_MEM_INFO_T *pstStatus,CVE_LK_OPTICAL_FLOW_PYR_CTRL_T *pstLkOptiFlowPyrCtrl,
MBP_BOOL_E bInstant)

参数说明：

Parameter name Description input/output
pCveHandle Pointer to the handle, can not be null output
astSrcPrevPyr[] An array of Pointers to previous layer data input
astSrcNextPyr[] An array of Pointers to next layer data input
pstPrevPts Pointer to CVE_LK_POINT data of previous frame input/output
pstNextPts Pointer to CVE_LK_POINT data of current frame input/output
pstStatus Lk point state output
pstLkOptiFlowPyrCtrl LK optical flow control parameter pointer,can not be null input
bInstant Return the result flag in time input

返回值：

Return value Description
0 success
non-zero failure

调用约束：

The value range of u8MaxLevel in CVE_LK_OPTICAL_FLOW_PYR_CTRL_T is [0, 3], and the number of corresponding
pyramid layers ranges from 1 to 4.
Only the 7 x 7 pixels around the feature point are used to calculate Ix, Iy, and It in the following optical flow equation:
where Ix indicates the horizontal offset of the current image, Iy indicates the vertical offset of the current image, and
It indicates the difference between the current image and the previous frame of image.
