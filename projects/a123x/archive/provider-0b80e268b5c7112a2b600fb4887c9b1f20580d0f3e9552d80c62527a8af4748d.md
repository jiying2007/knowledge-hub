## 怎么查

在A123X工作区调用既有Provider入口：

```bash
rtk bash ~/codex/scripts/knowledge-provider.sh context \
  --cwd "$PWD" \
  --query "平台知识库" --task-type runbook --limit 16 --context-budget deep --json
```

检索API可以将query改成MBI_VENC_GetStream、MBI_AI_GetFrame或MBI_ADLA_Forward；主题查音频ASP、SC5336P、Wi-Fi SDIO、低功耗、eMMC OTA等。context返回当前受治理条目和位置，先读对应知识卷及章节，再判断是否需要核源码/PDF。summary-json有4096字节投影上限，可能截去后面的条目；需要完整目录用json。当前evidence-pack辅助通道曾返回PROVIDER_RESPONSE_INVALID，不把它当作读取保证；context和归档对账分别验证。
