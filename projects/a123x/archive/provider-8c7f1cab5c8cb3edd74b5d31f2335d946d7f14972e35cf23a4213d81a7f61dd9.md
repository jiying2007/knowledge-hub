### brief

@brief Import audio samples from an audio buffer with a specific channel. The value of the FrameSample member of the @ref AI_ASP_CONFIG_S determines the number of samples that are imported in each call.
  Call this function once for each audio channel from audio buffer.
  Only support 2 bytes (short) sample format.
  The value of stride defines the number of samples to skip between each read, and the channel layout of audio buffer to read from should be stored in interleaved way.

@param[in] handle         pointer of ASP instance which created by @ref aml_asp_create
@param[in] in             pointer of audio buffer where stored the audio sample need to be processed
@param[in] stride         input buffer stride
@param[in] channel_id     channel of audio to read from
@param[in] channel_type   audio type of audio to read from, ref to @ref ChannelType

### return

@return    samples count has been imported in this call
