用途：

Creates thresholding task for U16 data to 8-bit data.

文档声明（与当前头文件分别留证）：

MBP_S32 MBI_CVE_Thresh_U16(CVE_HANDLE *pCveHandle, CVE_SRC_IMAGE_T *pstSrc, CVE_DST_IMAGE_T
*pstDst,CVE_THRESH_U16_CTRL_T *pstThrU16Ctrl, MBP_BOOL_E bInstant)

参数说明：

Parameter name Description input/output
pCveHandle Pointer to the handle, can not be null output
pstSrc Pointer to the source data, can not be null input
pstDst Pointer to the output data, can not be null. output
pstThrU16Ctrl Thresh S16 control parameter pointer,can not be null input
bInstant Return the result flag in time input

返回值：

Return value Description
0 success
non-zero failure

调用约束：

The algorithm has the following two modes of operation:
CVE_THRESH_U16_MODE_U16_TO_U8_MIN_MID_MAX
0<=lowThr<=highThr<=65535; 0<=minVal、midVal、maxVal<=255
CVE_THRESH_U16_MODE_U16_TO_U8_MIN_ORI_MAX
0<=lowThr<=highThr<=255; 0<=minVal、maxVal<=255.
Isrc1(xi,yi) corresponds to pstSrc, Iout(x0,y0) corresponds to pstDst, and mode, lowThr, highThr, minVal, midVal,
and maxVal correspond to enMode, u16LowThr, u16HighThr, u8MinVal, u8MidVal, and u8MaxVal. For details,
see Figure 2.13.
Figure 2.13 Four Thresh_U16 threshold modes
