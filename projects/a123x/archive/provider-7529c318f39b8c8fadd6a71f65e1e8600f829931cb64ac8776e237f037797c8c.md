调用约束：

The algorithm has the following eight modes of operation,For details, see CVE_THRESH_MODE_E.
THRESH_MODE_BINARY
No value needs to be assigned to midVal and highThr.
THRESH_MODE_TRUNC
No value needs to be assigned to minVal, midVal, and highThr.
THRESH_MODE_TO_MINVAL
No value needs to be assigned to midVal, maxVal, and highThr.
THRESH_MODE_MIN_MID_MAX
THRESH_MODE_ORI_MID_MAX
No value needs to be assigned to minVal.
THRESH_MODE_MIN_MID_ORI
No value needs to be assigned to maxVal.
THRESH_MODE_MIN_ORI_MAX
No value needs to be assigned to midVal.
THRESH_MODE_ORI_MID_ORI
No value needs to be assigned to minVal and maxVal.
Isrc(xi,yi) corresponds to pstSrc, Iout(x0,y0) corresponds to pstDst, and mode, lowThr, highThr, minVal, midVal,
and maxVal correspond to enMode, u8LowThr, u8HighThr,u8MinVal, u8MidVal, and u8MaxVal in
CVE_THRESH_CTRL_T. For details, see Figure 2.11.
