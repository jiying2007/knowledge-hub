## 结论

按读 ID、Sensor 限时出流、SoC 收帧、ISP 出图四层测试。读 ID 与限时出流无需 IQ。当前 CSI_CD 的 receiver/MCLK/VI/IPP 路由和真实帧仍待板端确认，正式 SC5336P Amlogic IQ 缺失；不能把 Host 测试、交叉构建或寄存器读回解释为图像采集及产品验收通过。

## 1. 硬件前提

1. 先确认模组实际供电和针序。裸芯片侧 AVDD 为 2.8V、DOVDD 为 1.8V、DVDD 为 1.5V；模组输入可能经过稳压，不得直接按裸芯片规格接模组入口。
2. 准备正确上电时序和 24MHz MCLK。ID 与 stream 工具不控制供电、GPIO 或 MCLK。
3. CSI_CD 候选 I2C 为 I2C2 / GPIOP0/P1；板端节点编号、pinmux、装配、上拉电平和物理通路必须核实。
4. 当前工具固定使用 7-bit 0x30，对应 SID 低。停止其他 Sensor owner，避免竞争；不做共享总线全地址扫描。
5. 裸芯片 A6 为 NC，C6 必须接 DOVDD，不能沿用旧相机 RESET/PWDN 语义；模组控制线按实际电路确认。

## 2. I2C 识别

仅在已确认设备节点为 /dev/i2c-2 时，板端执行：

```sh
sc5336p-id --bus 2
echo $?
```

工具读取 0x3107/0x3108，预期 chip_id=0xce50、expected=0xce50。输出同时注明 capture_verified=false、iq_verified=false。

| 返回值 | 含义 |
| --- | --- |
| 0 | ID 匹配 |
| 1 | 节点打开、占用或 I2C 访问/传输失败 |
| 2 | 参数错误 |
| 3 | 读到 ID，但不匹配 |

读操作包含发送 16-bit 寄存器地址指针，不写初始化及出流配置。ID 成功仅证明芯片识别，不证明 MIPI 收帧。

## 3. Sensor 限时出流

工具为 sc5336p-stream，可用 --help 查看参数；接受 --bus 和 --seconds，时间范围 1 至 30 秒，首次建议 5 秒。它会初始化 Sensor 并写出流寄存器，因此执行前须确认目标设备、独占 ownership、电气及 MCLK、恢复路径；本次会话没有执行或授权代理操作具体设备。

预期中间状态为 sensor_stream_register=1，同时 csi_verified=false、raw_captured=false、iq_used=false。正常结束预期 sensor_test_result=0、stream_off_result=0。退出会尝试停流，包括部分初始化失败后的清理；清理返回成功不等于对停流寄存器做了回读确认。

该工具不配置 SoC CSI、不采 RAW。成功只证明初始化、出流位读回及停流写入流程，不能证明物理 MIPI 数据或接收端正常。

## 4. SoC 收帧

sc5336p-rx 为显式实验构建，不进入正式安装：

- --plan 不加载库、不访问设备。
- vi 阶段成功只说明请求的配置/清理调用成功，不说明收到帧。
- ipp 阶段尝试取得帧并报告元数据，不输出 RAW 文件；独立 IPP 前置条件仍待板端验证。
- --run 会改变时钟、receiver、VI、Sensor 及可选 IPP 状态，需设备操作授权和正确路由。
- --seconds 不保证阻塞中的 SDK/kernel ioctl 能在指定时长内返回。

不得根据 CSI_CD 名称把 rx/clock/vi 都填为 2。现有原生 sample 仅开放显式 0/0/0，CSI_CD/RX2 在完整路由实现并验证前拒绝。实验工具的显式索引也不能替代真实路由证据。

收帧验收需观察真实帧、递增的帧号或时间戳、实际帧率和接收错误，并另行取得图像内容核验。当前适配模式为 2880×1620@30fps、RAW10、2-lane。不能仅以 VI 配置返回成功认定采集通过。

## 5. ISP 与画质

真实收帧后，再验证 ISP、预览和编码。正式 SC5336P Amlogic IQ 当前缺失；SC410 linear donor 为显式实验接口，默认不加载或安装，不能视为正式调参或画质验收。

后续分别验证实际分辨率/帧率、曝光响应、颜色、条纹/花屏、丢帧及反复启停恢复。当前未形成板端采集、RAW 内容、画质、长稳或产品放行证据。
