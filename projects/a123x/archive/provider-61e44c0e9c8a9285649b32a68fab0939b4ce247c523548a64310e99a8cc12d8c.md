# A123X：MBI_CVE_DMA的头文件和手册声明有什么差异

MBI_CVE_DMA 不能直接照文档声明编写调用。源参数类型在头文件为CVE_DATA_T*，文档为CVE_SRC_DATA_T*。是否为等价别名仍需核对，不据名称差异直接认定ABI不兼容。 当前开发应包含匹配头文件，并将文档侧差异作为待核问题；实际库导出和参数布局须另验，不擅自改头文件或强转消除差异。
