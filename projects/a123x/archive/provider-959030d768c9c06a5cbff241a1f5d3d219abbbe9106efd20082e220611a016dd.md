用途：

Creates an adaptive threshold task for gray-scale images.

文档声明（与当前头文件分别留证）：

MBP_S32 MBI_CVE_ADP_THRESH(CVE_HANDLE *pCveHandle, CVE_SRC_IMAGE_T *pstSrcImage0, CVE_SRC_IMAGE_T
*pstSrcImage1, CVE_DST_IMAGE_T *pstDstImage, CVE_ADP_THRESH_CTRL_T *pstAdpThreshCtrl, MBP_BOOL_E
bInstant);

参数说明：

Parameter name Description input/output
pCveHandle Pointer to the CVE task handle. input/output
pstSrcImage0 First source image. input
pstSrcImage1 Second source image. input
pstDstImage Destination image. output
pstAdpThreshCtrl Adaptive-threshold control parameters. input
bInstant Specifies whether the task result is waited for before the call returns. input

返回值：

Return value Description
0 Success.
non-zero Failure.

调用约束：

The control structure is CVE_ADP_THRESH_CTRL_T . u8HalfMaskX and u8HalfMaskY specify the half-mask dimensions;
u8RateThr , u8ValueThr , s8Offset , and u8MaxValue provide threshold parameters; u8Mode selects BINARY or
BINARY_INV . Exact formulas are not defined in the supplied header.
