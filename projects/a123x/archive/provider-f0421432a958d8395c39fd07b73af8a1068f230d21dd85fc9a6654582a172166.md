### brief

@brief Export audio samples to a user audio buffer with a specific channel. The value of the FrameSample member of the @ref AI_ASP_CONFIG_S determines the number of samples that may be exported in each call.
  Call this function once for each audio channel to user audio buffer.
  Only support 2 bytes (short) sample format.
  The value of stride defines the number of samples to skip between each write. the channel layout of audio buffer to write to should be stored in interleaved way

@param[in] handle         pointer of ASP instance which created by @ref aml_asp_create

@param[in] stride         output buffer stride
@param[in] channel_id     channel of audio write to

### return

@return    int            return the exported Frame Sample
