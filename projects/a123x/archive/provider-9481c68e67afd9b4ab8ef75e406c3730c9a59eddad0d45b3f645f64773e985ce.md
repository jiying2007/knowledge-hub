# A123X 调试实现审查结论

2026-10-22，对调试配置、脚本、包安装、测试与手册进行了只读作者自审，结论为 needs-fix。未修改实现，未操作设备或发布。此记录是 reviewing candidate，不能作为独立评审或产品放行。

确认三个问题：

1. P1：gdbserver 的 TCP host 参数不限制监听地址。手册以回环地址示例结合隧道，实际会暴露通配地址监听。已通过随附二进制的 remote_prepare 反汇编核验，并与 GDB 官方手册交叉验证。仅在用户按文档启动时触发。建议使用 SSH stdio transport，或落实真实访问限制并核验监听。
2. P1：board-diag 仅对顶层采集命令设置超时。BusyBox timeout 不终止整个进程组，后代持有输出管道时仍会阻塞。隔离 fixture 让采集命令派生等待六秒的子进程，配置两秒期限，实际六秒多才返回。建议将子进程组和管道纳入统一期限并补回归。
3. P2：board-diag 脱敏正则只处理部分首字母大小写，漏掉全大写密码和令牌字段。合成日志复现了大写字段保留、小写字段删除的结果。建议大小写无关匹配并覆盖混合大小写。

既有三个测试模块共 45 项本轮全部通过，但缺少上述反例。两个仓库 diff whitespace 检查通过。未重新构建内核或镜像，未执行板级验证；这些证据不能替代设备验收。问题均未修复，下一步为修复、补回归及独立审查。

可复用经验：启动 BusyBox shell 不代表测试中的 timeout 也来自 BusyBox；管道字节上限不等于整体期限；gdbserver 地址参数的表面含义需以实际监听实现为准。
