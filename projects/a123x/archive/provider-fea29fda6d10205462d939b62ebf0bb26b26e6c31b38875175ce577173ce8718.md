# A123X ADLA2与ADLA3区别及F20使用边界

- captured_at / last_verified：2026-10-21，Asia/Hong_Kong。
- subject：project:a123x；topic：a123x-dual-npu；status：reviewing candidate；AI-assisted。
- 来源：本地A123X Datasheet 0.4、Quick Reference Manual 0.4和当前C5 SDK。是资料/源码核对，不含模型转换、设备推理或性能实测。

## 1. 结论

A123X集成第二代ADLA2与第三代ADLA3。ADLA2主要面向整数卷积类网络；ADLA3扩展低比特、浮点、混合精度和Transformer能力，也能执行CNN。不能把它们视为两颗完全相同、仅频率不同的NPU。

| 项目 | ADLA2 | ADLA3 |
|---|---|---|
| 功能摘要命名 | NPU1 | NPU2 |
| 标称峰值与精度 | 4 TOPS，INT8×INT8 | 8 TOPS，INT4×INT8 |
| 支持精度摘要 | INT8、INT16 | INT4、INT8、INT16、FP8、FP16、BF16 |
| 定位 | CNN检测、分类等整数视觉推理 | CNN及Transformer/ViT/轻量语言模型等，支持混合精度量化 |
| INT8 MAC引擎 | 2048 MAC/周期 | 2048 MAC/周期 |
| FP16/BF16 MAC引擎 | 本节没有对应支持声明 | 1024 MAC/周期，见具体操作类型 |
| 片内RAM | 摘要标512KB | 摘要标512KB |
| 算子/张量形状 | 需按ADLA2约束转换 | 多项batch、通道、维度约束扩展，仍需按ADLA3约束转换 |

依据：Datasheet功能摘要印刷页2–3、§6.5.2印刷页123起、§6.5.3印刷页125起；QRM功能摘要印刷页2–3。以上不是声称所有框架算子均在硬件执行，必须以转换覆盖率和CPU fallback结果判断。

## 2. 为什么不能把4T+8T当作12T INT8

两组峰值用了不同乘法精度：4T为INT8×INT8，8T为INT4×INT8。降低位宽可提高计算密度，但模型准确率、量化格式、算子支持和访存方式都会影响端到端结果。

Datasheet两块的INT8 MAC/周期均列2048，因此仅凭“8T比4T大一倍”不能推出同一个INT8模型在ADLA3快一倍。实际还受时钟、电压、算子映射、CPU回退、DDR带宽、调度和前后处理影响。两个NPU同时工作不代表单个模型自动拆分，也不代表不同精度的数字可以相加为统一精度性能。

标称算力不等于帧率或语言模型tokens/s；片内512KB也不是可存放整个模型/SLAM地图的容量。模型权重、激活、工作区与缓存仍需系统DDR预算。

## 3. 原理图和SDK名称对应

| 名称体系 | ADLA2 | ADLA3 |
|---|---|---|
| 功能摘要 | NPU1 4T | NPU2 8T |
| 板级供电网/电源域命名 | VDD_NPU2、NPU2_SRAM | VDD_NPU3、NPU3_SRAM |
| C5设备树节点 | adla@fe096000 | adla3@fe098000 |
| compatible | amlogic,adla-gen2b | amlogic,adla-gen3b |
| power-domain | PDID_C5_NNA2 | PDID_C5_NNA3 |
| SDK硬件版本字符串 | r3p3 | r4p2 |

当前`meson-c5.dtsi`约323–365行声明了独立寄存器、中断、时钟和电源域，两者配置时钟都写1GHz；这是源码配置，不能当作设备实际频率或稳定性结果。原理图NPU2/NPU3的数字更接近ADLA代次命名，不能与摘要NPU1/NPU2按字面直接混用。

CB400/EVT1采用独立供电支路，电源额定电流差异不能直接推导推理速度或实际功耗倍数。不得为比较性能直接手写PWM/电压，须按SoC电压规范、板级电路和BSP适配验证。

## 4. F20使用建议

- CNN人/宠物/障碍物检测：先评估ADLA2转换与端到端时延，再用同输入/精度要求在ADLA3比较；“跟踪”还包含CPU或其他处理，不把整个流程都计为NPU。
- Transformer、ViT和端侧语言模型：优先评估ADLA3，检查实际转换工具、精度、目标芯片/运行库版本和算子分配；硬件支持不等于已具备可交付模型。
- 多模型并行：核运行库如何选择设备、并发上下文、模型装载与释放、DDR/媒体竞争；没有现场证据不承诺两块自动分担。
- SLAM：传统扫描匹配、特征匹配、位姿图/回环优化主要消耗CPU、DDR及带宽；学习特征/深度等可评估NPU加速，但不会把整个SLAM内存和实时性自动消除。
- SED：另有专门声音事件检测硬件，不能把它等同于上述两块通用NPU；AEC、ASR、TTS及LLM分别预算。

结合DDR/eMMC与SLAM容量评估（来源内引用：`F20-DDR-EMMC-CAPACITY.md`；尚未映射为 Hub 链接）确定模型常驻数量、上下文长度、媒体池及SLAM峰值，而不是按12T宣传值选择内存。

## 5. 模型验证最小记录

记录模型原始/转换文件hash、转换器及运行库版本、目标ADLA代次、输入形状、量化/精度、算子覆盖/CPU回退、权重/工作区/峰值DDR、冷启动装载与稳定推理时延、准确率、功耗和温度；并行SLAM/视频/音频/无线时重新测，不把单模型结果用于整机。
