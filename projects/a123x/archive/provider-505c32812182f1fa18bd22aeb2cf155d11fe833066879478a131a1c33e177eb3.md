用途：

Creates a Histogram of Oriented Gradients (HOG) task.

文档声明（与当前头文件分别留证）：

MBP_S32 MBI_CVE_HOG(CVE_HANDLE *pCveHandle, CVE_SRC_IMAGE_T *pstSrcImage, CVE_SRC_MEM_INFO_T
*pstSrcMem, CVE_DST_IMAGE_T *pstDstImage, CVE_HOG_CTRL_T *pstHogCtrl, MBP_BOOL_E bInstant);

参数说明：

Parameter name Description input/output
pCveHandle Pointer to the CVE task handle. input/output
pstSrcImage Source image. input
pstSrcMem Source memory buffer used by the task. input
pstDstImage Destination image. output
pstHogCtrl HOG control parameters. input
bInstant Specifies whether the task result is waited for before the call returns. input

返回值：

Return value Description
0 Success.
non-zero Failure.

调用约束：

The control structure is CVE_HOG_CTRL_T . u8HogGamma enables/disables HOG gamma processing; u8HogCellSize is
documented as 4 or 8; u8HogOShift is documented in the range [0,31]. The header does not define the exact HOG
descriptor layout.
