# A123X CVE Filter能否直接复制老C302X的参数列表

不能只按老芯片调用样式迁移：文档明确A123X/C302X2/C305X2的MBI_CVE_Filter增加pstDstMem，C302X/C308L没有该参数。滤波控制还包含5×5模板等设置。应以实际mbi_cve.h声明和配套库确定签名、辅助内存与生命周期；同一函数名不意味着二进制ABI相同，不能强制转换函数指针绕过编译检查。
