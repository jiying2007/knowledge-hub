# A123X 新增资产接入 SDK 布局的整改与验证

2026-10-22 完成本轮主机侧实现、DEVWIRE 固件构建与镜像核验，结论为 reviewing 候选。

根因是 DHD 在 vendor 阶段才安装到 `/lib/modules`，错过 SDK 原生模块迁移，随后被原有打包清理 hook 删除。此前只看构建退出码，缺少最终镜像模块存在性检查。

整改沿用 SDK 选择与加载入口：DHD 外置模块安装到 `/amlogic/ext_modules/bcmdhd.ko`；固件/NVRAM/CLM 到 `/lib/firmware/f20/f10-dhd`；config.txt 到 `/etc/f20/wifi/f10-dhd`；来源布局清单到 `/usr/share/f20/wifi/f10-dhd`。供应商原件和通用清理 hook 保持。五项补丁绑定 source-lock，并只应用于 OUT 副本。SDK rcS 先加载原生 cfg80211；产品 loader 核对模式、DT、竞争 owner、模块和数据后显式 insmod，保持 disabled 默认与有界等待。Dropbear 的 rootfs 安装依赖自身包构建安装，产品 vendor 只负责启动脚本。

已新增 SDK-INTEGRATION.md 统一接入规范，并同步组件、DHD、产品集成 README。16 项 Python 定向测试以及模块 Host UBSAN/模拟故障测试通过。三板配置检查：DHD 仅 DEVWIRE，CB400 仍为 W1U，EVT1 未选择 DHD。

DEVWIRE 完整构建 PASS，make 用时 576.430 秒；记录的前后源码摘要一致，包装器未报告规则漂移。保存镜像检查 PASS：5 制品身份正确，DHD/配套文件存在且 hash 正确，cfg80211/DHD vermagic 一致，默认 disabled；89 个 ELF 无缺失依赖；4 项 SWU 声明 hash 正确；sparse rootfs 展开身份与保存镜像一致；USB 容器检查通过，USB/SWU 四项核心载荷一致。

证据定位：`.tmp/sdk-layout-fix/host-validation.md`、`source-review.md`、`devwire-20261022/build.json`、`image-check/20261022T041915327156Z.json`。首次镜像检查对死宏的 ELF 字符串断言过强，按供应商实际 config_path 参数语义修正验证器后复验通过，未修改固件。
