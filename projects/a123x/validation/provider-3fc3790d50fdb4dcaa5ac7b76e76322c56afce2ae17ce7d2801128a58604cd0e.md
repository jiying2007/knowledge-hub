# A123X 开发网络 ADB 与 SSH 默认启用验证

状态：源码与隔离主机验证通过；完整固件及实板验证待执行。

## 范围与行为
- CB400、F20 DEVWIRE、F20 EVT1 开发 defconfig 默认启用 ADB、SSH、AML_DEBUG、AML_ADB_DEV_NETWORK、AML_SSH_DEV_NOAUTH、AML_SSH_DEV_LAN。
- 网络 ADB 在全部 IPv4 地址监听 TCP5555，不要求用户公钥。SSH 网络模式监听 TCP22，不要求用户公钥或密码；沿用已有空 root 密码前提，不修改现有密码，保留主机密钥与加密。
- 新增 SDK Kconfig 选项与 S88adbd-network。通过现有 libcutils 环境属性 PROP_service.adb.tcp.port=5555、PROP_ro.adb.secure=0、PROP_ro.secure=0 配置现有 SDK adbd，无第三方源码修改。
- S88 先准备 FunctionFS、启动 adbd，S89 复用同一 daemon；没有 UDC 或 USB 初始化失败时不停止已启动的网络 daemon。检查进程与 TCP LISTEN 后才报告就绪；端口占用、超时明确失败。
- 关闭 AML_DEBUG 或 AML_ADB 时，Kconfig 撤销网络 ADB。vendor 安装规则同时检查 AML_DEBUG，禁用时删除旧 S88 并写回 USB 策略；SSH 恢复公钥策略。
- 保留全部既有无关 dirty，未修改活动 SDK .config；未执行完整构建、提交、推送或设备操作。
