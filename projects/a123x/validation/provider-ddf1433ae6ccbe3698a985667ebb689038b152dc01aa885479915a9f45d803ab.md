# A123X SDK 调试能力落地验证

日期：2026-10-22。范围为源码接入与隔离验证，完整固件构建由用户手动执行，未操作设备。

## 实现

- 复用 SDK Kconfig、package-auto-build-generate、aml_generic_package、内核 fixup 和 rootfs 配置生成流程。
- 三板 AML_DEBUG 默认开启；core 和 ftrace 显式选择；动态日志调用点编译支持默认开启，采集默认关闭。
- board-info、限时限额诊断包、pstore 私有导出、core launcher、私有 tracefs 实例采集及主机符号保存入口已接入。
- 新增 strace 6.17、ethtool 6.15、tcpdump 4.99.7/libpcap 1.10.7、iproute2 6.12.0 固定源包；复用工具链 gdbserver、SDK iw/iperf2/libnl。
- 工具默认不启动网络监听或抓包服务；默认诊断不读取凭据、完整命令行或业务目录。

## 验证证据

- 46 项回归通过：构建入口、板型切换、模块导出、ADB/SSH、12 项新增诊断测试。
- 新增 12 项测试另经 SDK 同版原生 BusyBox 1.32.0 ash 执行通过，包括实测 RLIMIT_CORE=67108864 字节。
- 三板 SDK Kconfig 隔离解析，默认依赖、关闭模式、core/trace 开关检查通过，活动配置不变。
- 三板内核 defconfig 经真实 SDK fixup 后 olddefconfig 解析通过：pstore、动态调试、SysRq、hung-task、DMA buffer 统计、core、ftrace 的依赖可满足。可选项仅在验证配置中开启。
- 新增第三方工具通过真实 SDK 包规则完成隔离 AArch64 交叉编译并安装到临时 rootfs；gdbserver 从对应编译器 sysroot 复制。
- rootfs 安装、工具 hash、可执行权限、shell 语法、关闭模式不安装、动态依赖核验通过。
- strace、ethtool、tcpdump 的未剥离 ELF 与 rootfs 程序 Build ID 一致；debug-symbols 真实目标在临时输出目录执行成功，SHA256清单通过。该测试使用已有内核ELF验证导出机制，不宣称它是本轮新调试内核。
- 原生 SDK BusyBox 的 timeout/stat/sed 功能已验证；未修改其原始配置文件。

## 负结果与修复

- 初始 tcpdump 依赖未包含 SDK 架构 stamp，已改为 libpcap 实际安装 stamp，避免配置阶段先于依赖且避免每次无条件重编。
- SDK 通用 configure 不传该包 CPPFLAGS；为 tcpdump 使用标准 PRIVATE_CONFIGURE_CMDS 并限定 pkg-config sysroot，消除主机头文件污染。
- BusyBox core 单位与主机 shell 不同，按 SDK 源码及真实 ash 资源限额修复为 64 MiB。
- 交叉工具链默认未给新增工具生成Build ID，显式增加链接选项以支持strip前后符号身份核对；不把缺失身份当作通过。
