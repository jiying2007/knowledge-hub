# PCR02 App Module

- 项目 ID：`pcr02-app`
- 所属组：`pcr02`
- 事实边界：以 `registry/repositories.json` 中 `repo_id=pcr02-app` 的 Git remote key 为准。
- 当前知识：`projects/pcr02-app/current/`
- 决策：`projects/pcr02-app/decisions/`
- 验证：`projects/pcr02-app/validation/`
- 归档：`projects/pcr02-app/archive/`

本入口承接 app 模块长期接口、运行时行为和验证结论；源码仓本地规则仍由源码仓维护。
