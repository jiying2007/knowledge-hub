# Agent Dev Kit

- 项目 ID：`agent-dev-kit`
- 所属组：`agent-tools`
- 事实边界：以 `registry/repositories.json` 中 `repo_id=agent-dev-kit` 的 Git remote key 为准。
- 当前知识：`projects/agent-dev-kit/current/`
- 决策：`projects/agent-dev-kit/decisions/`
- 验证：`projects/agent-dev-kit/validation/`
- 归档：`projects/agent-dev-kit/archive/`

该入口用于 ADK 资产、工作流、门禁和子仓边界知识；不把父仓 `llm-agent` 的事实混入本项目。
