# X5 SDK V1.1.2 DDR、eMMC、Camera 与 Wi-Fi 适配清单

- SDK 基线：`LNX6.1.83_PL5.1_V1.1.2`
- 状态：本地 Release Notes 与固定源码基线核对完成；实物 BOM 和最新在线 AVL 仍需 FAE 确认

## 1. 结论与证据等级

V1.1.2 没有独立命名为 QPL 的文件，但 Release Notes 第 9～15 页内嵌了 `Approved Vendor List`，可作为随该 SDK 发布的 AVL/QPL 基线：

- 第 10 页：DDR Support List；
- 第 12 页：eMMC Support List；
- 第 13 页：Camera Sensor Support List；
- 第 15 页：Wi-Fi/Bluetooth Support List。

Release Notes 明确提示列表与 SDK 发布周期同步、可能滞后，最新选型应查询在线 Approved Vendor List。本文按以下等级解释证据：

1. AVL 列名：供应商明确列入当前版本支持清单；
2. 可送样：Camera 已完成驱动和效果开发；
3. 驱动/样例存在：源码具备适配资产，但不单独证明量产验证；
4. 手册标配：证明某一 EVB/Module 批次使用，不代表所有板卡版本。

## 2. DDR

## 4. Camera Sensor

Camera AVL 列出 30 款：

- Cvsens：`cv4006`、`cv2005`；
- SmartSens：`sc1336`、`sc1330t`、`sc230ai`、`sc231ai`、`sc235HAL`、`sc202cs`、`sc301iot`、`sc835SL`、`sc035hgs`、`sc132gs`、`sc233HGS`；
- Silicon：`JX-F37`；
- OmniVision：`ov5640`、`ox02c1s`、`os08c10`、`ov5647`、`ox05b1s`、`ov50h40`、`ov9782`、`ov9281`；
- Sony：`imx477`、`imx415`、`imx586`、`imx219`、`imx678`、`IMX900`；
- Infineon ToF：`irs2875`、`irs2381c`。

Release Notes 定义“可送样”为具备完整驱动和 ISP 效果开发结果。标记可送样的型号为：`cv4006`、`sc230ai`、`sc231ai`、`sc235HAL`、`imx415`、`sc835SL`、`imx678`、`sc132gs`。其余列名型号具备驱动和初步点亮效果。

固定源码基线中还能看到约 49 个 sensor/SerDes 驱动单元和约 28 个 `vp_sensors` 应用配置；这些资产比 AVL 更宽，不能直接提升为正式 QPL。手册明确的 EVB 常用模组为 `SC230AI`、`SC132GS`、`IMX415`，Module 树莓派风格接口还列出 `IMX219`、`IMX477`、`OV5647`。

文档与源码存在 `sc235HAL/sc235hai`、`sc835SL/sc850sl` 等命名差异，选型前必须让 FAE 按厂家完整料号确认。

|---|---|---|---|
| Realtek | `rtl8852bs` | SDIO | UART |
| Realtek | `rtl8733bs` | SDIO | UART |

| 希微 | `SWT6652` | SDIO | UART |
| 展锐 | `uwe5622` | SDIO | SDIO |

当前 release defconfig/镜像明确编译出 `AIC8800`、`RTL8852BS`、`RTL8723DU`、`RTL8723BS` 驱动栈。AVL 中的所有模组不一定都以同名独立驱动出现，不能据此推断芯片映射。

V2P0 手册描述板载 `FCS960K/FCS960KAAMD`，Release Notes 的板卡图另写 `CDW-47852BS`，可能对应不同硬件批次。实际板卡必须结合丝印、BOM、`ethtool -i wlan0` 和模块枚举确认。

## 6. 选型门禁

1. AVL 列名只是版本基线；量产前获取最新在线 AVL 和 FAE 书面确认。
2. DDR 换料同时核对 ADC2、miniboot、容量和压力/眼图测试。
3. eMMC 核对 CID、HS200 稳定性、寿命等级和掉电测试。
4. Camera 优先选择“可送样”模组；未标记型号需要自行完成效果与温漂验证。
5. Wi-Fi 核对模组实际芯片、总线、BT 接口、固件和认证区域。
6. 文档拼写与源码命名冲突时不自行归一化，提交 FAE 确认。
