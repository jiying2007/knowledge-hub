## 修复结果

Sensor 对已验证连接的瞬时 IPv4 缺失增加最多 3 秒复核，并受最后有效样本 5 秒新鲜度限制；缓存重读不延长新鲜度。复核期间阻止自动选网（含迟到扫描结果）及休眠。低功耗期间通过缓存推进恢复或超时，断连、失败终态、新请求与关闭清除待复核状态。

API 将后端采样失败作为未知观测返回 VS_ERROR_BUSY；确认无 IPv4 仍返回 VS_FAILURE 与空地址，避免混淆未知和确认丢地址。

WiFi bounded station 快照在 WPA 完成认证后只读核验内核 IPv4，兼容 DHCP 与静态 IPv4。无地址与 socket/ioctl 观测失败分别处理。此接口仍为 IPv4 契约，不证明二层断连或 IPv6 不可用，也未增加 IPv6-only 支持。
