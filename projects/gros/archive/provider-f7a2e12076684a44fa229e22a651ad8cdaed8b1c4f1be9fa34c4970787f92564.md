## A：十四次短暂状态异常

Sensor 十四次 linked=false、wifi_state=11，持续 1.012 至 1.030 秒，随后 linked=true、state=6。时间为：15 日 22:38:12、22:45:23、23:01:14；16 日 00:05:40、00:48:49、00:59:50、02:36:36、02:37:48、02:38:00、03:30:19、04:06:33、04:07:01、04:07:49、07:39:29。

后十次能直接对齐 IoT 主动断 MQTT；前四次 IoT 日志已轮转。07:39:29 样例：故障前 RSSI -38dBm，Sensor 在 29.680 上报未连接，IoT 在 29.702 主动断 MQTT；30.695 Sensor 恢复，31.837 MQTT 回调成功，32.987 连接循环完成恢复并重新订阅。约一秒状态异常造成约二至三秒业务中断。物理 WiFi 是否真的断开没有直接匹配证据；IPv4/采样异常为候选，未取得实际接口 IPv4 与 API 原始返回值。

另有八十一次 Monitor NORMAL 到 DISCONNECTED，不等于八十一次 APP 离线。弱网切换在异常上报后触发，部分 ACK 失败但 Task 仍打印发送成功，不能视作已切网。

## B：06:22 的独立 MQTT/RTM 故障

06:22:12 与 06:22:25 Agora RTM 报 LOCAL_TIMEOUT 随后重新登录；06:22:35.014 MQTT Connection lost，原因 unknown。35.066 的诊断显示原网络 wpa_state=COMPLETED，35.091 DNS 解析成功，36.132 MQTT 连接成功，38.092 完成恢复及订阅。

该事件没有对应 Sensor 未连接发布；不能归入 A。只能定位到传输/上层连接异常，尚不能在 AP 转发、上游网络、超时和服务端间定责。保留窗口没有 MQTT DNS resolution failed。WPA COMPLETED 不证明互联网或 MQTT 服务端健康。
