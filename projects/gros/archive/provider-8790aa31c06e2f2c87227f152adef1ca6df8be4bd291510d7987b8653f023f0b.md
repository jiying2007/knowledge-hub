## 跨层模式与原因边界

Sensor 保留窗口内十次 linked=false、wifi_state=11 均约 1.01 至 1.03 秒后恢复。五次有完整 IoT 对齐证据：Sensor 未连接上报后，IoT 主动断开 MQTT；状态约一秒恢复，MQTT 数秒后连接、重新订阅。09:12:28 是完整样例。

这条模式可解释 APP 离线，但不能证明 00:22 使用完全相同的底层触发路径。历史 Sensor c0c0d2e 的关键日志行号与现场相符：普通查询失败保留旧连接；状态仍 NET_CONNECTED、失败返回且 IP 为空时，清连接并发布 WIFI_STATE_ERROR。优先假设为瞬时 IPv4 快照缺失或真实 IPv4 短失，尚无现场 API 原始字段与内核地址证据区分。
