# PCR02 SSC305 OTA 互升交付 Runbook / 检查清单

- 文档版本：v1.0
- 生效日期：2026-09-29
- 适用产品：PCR02，SSC305，AP6303BH，512M，V2.0
- 适用范围：旧版 static customer 首次迁移、后续 dynamic customer OTA、release/debug 互升
- 代码基线：以当前工作区 `ota.mk`、`ota_start.sh`、`ota_upgrade.sh` 和 rootfs customer 挂载逻辑为准

## 1. 交付原则

以下任一项不满足，不得发布 OTA 包：

- [ ] 不整写 `ubia`，OTA layout 不包含 `ubia.bin`。
- [ ] 不升级 `data`、`factory`、`ota`，保留三个 UBI volume 的业务数据。
- [ ] customer 镜像直接写 `/dev/ubi0_3`，不使用 `/data/ota/customer.ubifs` 或 `/ota/customer.ubifs` 暂存。
- [ ] 旧版 static customer 首次迁移包必须同时包含 `rootfs` 和 `customer`。
- [ ] static customer 收到无 rootfs customer 包时必须在写分区前拒绝升级。
- [ ] dynamic customer 后续升级支持带 rootfs或不带 rootfs，两者均自动完成并自动重启。
- [ ] release/debug 互升包必须包含 `customer`，由目标 customer 的 `build_type` 决定启动模式。
- [ ] 含 rootfs 的 OTA 必须由静态 BusyBox 重启监控完成重启，不执行人工 `reboot`。
- [ ] release 正常启动后 `/customer` 已挂载只读 UBIFS，`/customer_ro`、`/tmp/customer_ro` 均不存在；若挂载失败，先排查挂载故障，不将目录残留单独判作清理失败。
- [ ] debug 启动后 `/tmp/customer_ro` 是 UBIFS lower，`/customer` 是 OverlayFS。
- [ ] 禁止使用模糊命令 `ps -A | grep prog_ | ... | kill -9`；该命令会匹配 FWFS 参数 `--prog_size`。

|---|---|---|---|

## 8. 失败判定与处置

| 现象 | 判定 | 处置 |
|---|---|---|
| static customer + 无 rootfs 被拒绝 | 预期安全拒绝 | 确认没有分区写入；改用含 rootfs 包 |
| customer/customer lower `EBUSY` | 升级失败 | 保存 `fuser`、mount、进程引用；禁止强制继续写 customer |
| `otaunpack return=143` 且载荷已完成 | 成功收尾时序错误 | 判 FAIL，检查成功脚本是否提前重启 |
| rootfs 写完后未自动重启 | rootfs 重启保护失败 | 保存串口；不要调用动态 `reboot`，按故障流程受控断电恢复 |
| 手动 `reboot` 报 fault/段错误 | 已覆写在线 rootfs | 不再执行 rootfs 命令；受控断电并判定本次自动重启失败 |
| 重启后 customer 仍为 static/ubiblock | 迁移失败 | 禁止继续发 regular customer 包，检查 migrator 顺序和日志 |
| release 出现 overlay 或 customer_ro | 挂载或模式切换异常 | 检查目标 `build_type`、`/proc/mounts`、lower 卸载及 overlay/目录清理日志；`/customer` 挂载失败时不会清理 `/tmp/customer_ro` |
| data/factory/ota 哨兵变化 | 数据保持失败 | 立即阻断发布，检查 layout 是否包含 ubia/data/factory/ota |

失败时必须归档：OTA 包和 SHA256、layout、完整串口日志、升级前后版本、volume type/name、mount、df、状态文件以及哨兵对比。

## 11. 精确停止 prog_* 的调试命令

仅用于人工调试，不替代正式 OTA 流程：

```sh
for proc in /proc/[0-9]*; do
    [ -r "$proc/comm" ] || continue
    name=$(cat "$proc/comm" 2>/dev/null)
    case "$name" in
        prog_*) kill -TERM "${proc##*/}" 2>/dev/null ;;
    esac
done
sleep 2
for proc in /proc/[0-9]*; do
    [ -r "$proc/comm" ] || continue
    name=$(cat "$proc/comm" 2>/dev/null)
    case "$name" in
        prog_*) kill -KILL "${proc##*/}" 2>/dev/null ;;
    esac
done
```

该命令按进程名匹配，不会因 FWFS 参数 `--prog_size` 误杀 `fwfs`。
