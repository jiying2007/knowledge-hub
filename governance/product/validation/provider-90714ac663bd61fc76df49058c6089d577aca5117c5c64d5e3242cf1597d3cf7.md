## 可复用操作原则

1. 没有 Git 或远端时，仍可显式指定已注册的执行项目、检索项目和归档主体；未知归属须保留 unassigned 或形成受控注册提案。
2. 执行上下文、检索范围和归档主体独立，不将检索结果自动写到执行项目，也不将候选当成 active 事实。
3. 源码必须绑定精确发布身份与实际执行清单；数据迁移必须绑定独立审查、真实请求、输入哈希、写入计划和 CAS。
4. 维护屏障只阻断 Provider 新调用。共享源码编辑需协调暂停，再冻结、整合和验收，不能用过去的快照覆盖后来改动。
5. 本机权限输入使用稳定的私有配置路径与批准哈希；测试恢复构建时必须显式重传，不允许静默回退到没有本机规则的构建。
