# Embedded Source Docs Archive

本目录只保存已经退役的 embedded 外部 source 快照。

## 边界

- 这里不是 active `domains/embedded/standards/`、`domains/embedded/runbooks/` 或团队规范入口。
- 子目录名对应 `registry/sources.json` 中的 retired source id。
- 子目录内保留的是迁移时按 manifest 固定下来的旧 source 文档副本，用于审计、追溯和后续人工拆分。
- 不得把这里的内容直接当作当前有效事实、团队标准或项目 runbook。
- 若需要提升为 active 知识，必须新建或更新对应 canonical 文档，并走 owner/review、registry、index 和验证门禁。
